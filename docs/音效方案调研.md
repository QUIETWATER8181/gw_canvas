# 音效方案调研（2026-11-06）

> 目标：给物理科普视频配「不廉价、不侵权、离线可用」的音效，并定一套可执行的配置规则。
> 结论先行：**不拉现成音效包，改成现场合成**；参考 sfxr/jsfxr 的合成思路，自己写 12 个预设。

## 1. 候选方案

| 方案 | 代表项目 | 许可 | 优点 | 问题 |
| --- | --- | --- | --- | --- |
| 经典 8-bit 音效生成器 | [jsfxr](https://github.com/chr15m/jsfxr)（463★） | Unlicense（公共领域） | 参数化、体积小、可复现 | 偏 8-bit，做转场/呼啸不够「现代」 |
| 同源 Go 版 | [jsfx](https://github.com/loov/jsfx)（585★） | MIT | 同上，算法清晰 | 同上 |
| 现成音效包 | freesound / 各种 CC0 包 | 混合（CC0/CC-BY/署名） | 质量高、真实录音 | 授权要逐条核、包体大、要联网/随包分发 |
| 商用音效库 | Epidemic / Artlist 等 | 订阅 | 质量最好 | 收费、不能随桌面端分发 |
| 现场合成（本方案） | `src/shared/sfx.ts` | 自有代码 | 无版权问题、离线、确定性、可调 | 只能做「合成类」音效，做不了真实录音 |

**为什么选现场合成**：

1. 这是桌面端产品，音效要能随安装包分发；第三方素材的许可（尤其 CC-BY 的署名要求）会让发布流程变复杂。
2. 物理科普视频最常用的恰恰是「合成类」音效：呼啸、转场、弹出、滴答、叮、上升、撞击。
3. 合成器是纯函数：同样的输入永远生成同样的 wav，导出可复现，也方便测试（探针能量化音量）。
4. 用户以后要加真实录音，仍然可以走 `asset_import` / 音轨，不冲突。

参考实现只借「噪声 + 扫频 + 包络」这套结构，代码是自己写的（没有拷贝 jsfxr 的参数表）。

## 2. 12 个预设与信号设计

| id | 时长 | 合成方式 | 典型用法 |
| --- | --- | --- | --- |
| `whoosh` | 0.55s | 带通噪声，截止频率 220→2400→回落，`sin(πk)^1.5` 包络 | 组合/代码图层快速进场 |
| `swoosh` | 0.35s | 更短更亮的带通噪声扫频 | 小元素、图片进场 |
| `riser` | 1.8s | 180→1620Hz 指数扫频 + 噪声，3→13Hz 颤音，能量随 k^1.4 | 蓄力、转场前 |
| `transition` | 0.5s | 柔和的带通噪声 + 90Hz 低频 | 镜头切换底噪 |
| `pop` | 0.14s | 420→147Hz 快速下滑正弦 + 指数衰减 | 标签、数据点 |
| `click` | 0.06s | 6kHz 噪声 + 2.4kHz 正弦，6ms 衰减 | 按钮、选项 |
| `tick` | 0.04s | 8kHz 噪声，4ms 衰减 | 计时、刻度 |
| `typing` | 0.6s | 5 个 110ms 间隔的短噪声+900Hz 正弦 | 文字逐字出现 |
| `ding` | 1.2s | 880/1320/1760Hz 三个正弦叠加，τ=0.32s | 结论、重点 |
| `success` | 1.0s | C5-E5-G5-C6 琶音，每音 160ms | 章节收尾 |
| `error` | 0.6s | 330→220Hz 两段短音 | 否定、错误假设 |
| `impact` | 0.7s | 70→42Hz 下滑正弦 + 1.2kHz 噪声，τ=0.16s | 碰撞、强调 |

统一处理：`tanh` 软削波、峰值 0.85、48kHz 单声道 16-bit PCM；导出混音时再转立体声。

## 3. 配置方案（给人和 AI 的默认规则）

1. **卡在画面节点**：`at` 取图层的 `start`/`end`，不要凭感觉写；差 0.2s 就会音画不同步。
2. **按元素类型选**：组合/代码→`whoosh`，文字→`pop`，图片→`swoosh`，形状→`tick`；
   重点→`ding`，收尾→`success`，否定→`error`，碰撞→`impact`，蓄力→`riser`。
3. **音量**：默认 0.8；有旁白压到 0.4–0.6；一段 12s 视频 4–8 个音效足够，别每个元素都配。
4. **淡入淡出**：音效轨自动 10ms 淡入、60ms 淡出，防爆音；不需要用户手调。
5. **自动铺**：左栏「音频 → 按图层入场铺音效」按上面的映射，给每个从中间开始的顶层图层配一条。
6. **agent**：`sfx_add({ preset, at, volume })`；它写进 `scene.audio`，`kind: "sfx"`。

## 4. 还没做

- 用户自带音效库 / 收藏 / 搜索（目前只能导入本地音频）。
- 波形编辑、变调、时间拉伸。
- 旁白自动 ducking（现在只靠音量手调）。
- 更真实的录音类音效（需要授权素材或录音）。
