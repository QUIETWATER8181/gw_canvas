已修：

- footer 挪进 `.lp-main`（`.lp-body` 之后），340px 时正文 278px、240px 时 178px；
- 左右栏可拖拽调宽：默认左 340 / 右 400，最窄左 240 / 右 280，双击复位，宽度记 `gewu.leftW/rightW`；

  音轨的起点/音量改成上下排 + `auto minmax(0,1fr) auto` 网格，不再被裁；
- 帮助弹窗「画布」页加了「布局」说明。

证据：`scripts/probe-panels.js` 在 240px 下媒体/音频/字幕/搜索四个 tab 的 `scrollWidth` 全部 ≤ `clientWidth`；

## 二、如何跑起来 / 验证

### 1. 类型检查（必须两个都过）

```powershell
$env:ELECTRON_RUN_AS_NODE=$null
.\node_modules\.bin\tsc.CMD --noEmit -p tsconfig.node.json   # 期望 exit 0
.\node_modules\.bin\tsc.CMD --noEmit -p tsconfig.web.json    # 期望 exit 0
```

> `pnpm` 不在当前 shell 的 PATH 上，别用 `pnpm typecheck`；用上面的本地 tsc。

### 2. 构建

```powershell
$env:ELECTRON_RUN_AS_NODE=$null
node node_modules\electron-vite\bin\electron-vite.js build
```

- 这个构建**经常卡在 `transforming...`**（本机老毛病）。卡住就 `taskkill /PID <pid> /T /F`，重试一次通常就过。
- **不要运行 `scripts/build.ps1`**：它为了解卡会 `Stop-Process node`，会把 DSH/当前会话的 node 一起杀掉。
- 构建产物在 `out/`；最后成功的一次产物：`out/renderer/assets/index-lhFgDFsy.js`。

### 3. 跑探针（推荐，全部用独立 user-data，别碰作者真实 `%APPDATA%\gewu-video`）

```powershell
$env:ELECTRON_RUN_AS_NODE=$null
$p = Start-Process -FilePath ".\node_modules\electron\dist\electron.exe" `
  -ArgumentList ".","--user-data=_testhome\ui-v4","--probe-file=scripts\probe-layout-v2.js","--probe-wait=2500","--log=_probe.log" `
  -PassThru -WindowStyle Hidden
$p.WaitForExit(120000)
Get-Content _probe.log -Encoding utf8 -Raw   # 找 [probe] 开头的 JSON
```

- Windows 上必须 `Start-Process ... -PassThru` + `WaitForExit`；直接 `& electron.exe` 会立刻返回，日志还没写出来。
- `--log=` 是主进程日志落盘（GUI 子系统收不到 stdout）。
- 探针都在渲染进程里跑；需要驱动内部状态时用 `window.__gewuDebug`（`App.tsx` 暴露的只读调试入口：`editor` / `getScene()` / `getTime()`）。

### 4. 假模型（不需要 Key）

```powershell

```

测试 user-data 下写 `config.json`（无 BOM）：

```json
{ "version": 1, "activeConnectionId": "mock",
  "connections": [{ "id": "mock", "name": "Mock", "kind": "openai-compatible",
    "baseUrl": "http://127.0.0.1:8787/v1", "model": "mock-deepseek", "key": "plain:bW9jaw==" }] }
```

新增的 `MOCK_MODE`：`batch`（一次 scene_batch 三个 op）、`sfx`（sfx_add 叮）。
原有：`text/inspect/frame/write/export/scene/bad/img/cmp/multi/kf/tts/check/slow/nostream/reject400/auth401/reasoning/empty/emptyDraw`。

## 六、坑（这轮新踩的，别再踩）

1. **PowerShell 不能用来批量改源码**：`Get-Content -Raw | Set-Content` 会把 UTF-8 当 ANSI，中文注释整份变 `鍥剧墖`。改源码只用 edit/write；这次靠 `git checkout -- src/engine/assets.ts` 救回来。必须用 PowerShell 写文件时用 `[IO.File]::WriteAllText(path, text, UTF8Encoding($false))`，且不要读中文源码再写回。
2. **`resources/gewu-tools.mjs` 改完先 `node --check`**：单引号字符串里再写单引号（如 `ease?:'linear|...'`）会把字符串截断。DSH 子进程加载插件失败时，报的是 `DSH session/new 失败：ACP session persistence flush failed`，完全指不到插件语法。
3. **`sendPrompt` 会挂到整轮结束**：探针测流式/暂停时不要 `await`，先 `const p = sendPrompt(...)`，轮询状态，最后再 `await p`。
4. **构建偶发卡死**：`transforming...` 不动就 taskkill 整棵进程树重试；不要跑 `scripts/build.ps1`（会杀所有 node）。
5. **探针合成拖动要等 ≥150ms**：`mousedown` 后 React 才挂 window 监听；90ms 会丢第一个 `mousemove`，裁剪/拖动结果偶发不对。
6. **`window.__gewuDebug` 是探针入口**：不要删；它只在桌面端，不对外暴露 DOM。
