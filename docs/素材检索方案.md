# 素材检索方案（2026-11-06）

> 目标：让 AI 和人能从网上找到物理示意图、实验照片、公式图，下载进当前草稿并合法使用。
> 结论：**只用免费、免 Key、许可证信息完整的图库**；网络能力收在主进程，agent 只能通过两个窄工具使用。

## 1. 数据源

| 源 | 接口 | Key | 许可 | 说明 |
| --- | --- | --- | --- | --- |
| Wikimedia Commons | `https://commons.wikimedia.org/w/api.php`（`generator=search` + `prop=imageinfo`） | 不需要 | 逐图标注（CC0 / CC BY / CC BY-SA / 公有领域…） | 物理示意图、公式 SVG/PNG、实验照片最全；`extmetadata` 直接给作者和许可证 |
| Openverse | `https://api.openverse.org/v1/images/` | 不需要（匿名有限流） | CC 系列 | 聚合 Flickr/Wikimedia 等；作为补充 |

没有选 Google/Bing 图片搜索：需要 Key、许可证不明、下载地址不可控。
没有选 arXiv/论文 PDF：版权与公式排版复杂，公式优先用 `g.math` 现场画。

## 2. 链路

```
渲染进程「搜索」面板 / agent 工具
        │  IPC（只传搜索词/结果 id）
        ▼
主进程 AssetSearch（electron/main/web-search.ts）
  ├── 搜索：Commons / Openverse → 结果 + 缩略图
  ├── 缩略图缓存到 userData/cache/search/<sha1>.<ext>
  │     渲染进程通过 gewu://cache/<file> 读取（CSP 已允许 gewu:）
  └── 下载：白名单主机 + 只收 image/* + ≤30MB + 重定向后再校验
        ▼
当前草稿 assets/<name>.<ext>
  + assets/credits.json（file/title/author/license/source/downloadedAt）
```

## 3. 安全边界

- **只有主进程能联网**；渲染进程 CSP 的 `connect-src` 没有外网，agent 也没有 web 工具。
- 下载主机白名单：`upload.wikimedia.org`、`commons.wikimedia.org`、`live.staticflickr.com`、
  `images.pexels.com`、`cdn.pixabay.com`。其他来源只展示、不下载。
- 缩略图只要求公网 https，并拒绝 localhost / 10.x / 192.168.x / 172.16-31.x（防 SSRF）。
- 重定向后再次校验主机；不合法直接拒绝。
- 单张 ≤30MB、缩略图 ≤6MB；超时 30s；网络错误自动重试一次。
- 文件名做安全化（去掉路径分隔符和非法字符），不覆盖已有文件（重名加 `-1`）。

## 4. 使用方式

**界面**：左栏「搜索」→ 输入关键词（英文命中率更高）→ 选 Commons/Openverse → 「插入画面」。
插入会按播放头放到时间轴、等比缩到画面 55%、加 0.45s 渐显。

**agent**：

```js
asset_search({ query: 'Malus law', source: 'commons', limit: 12 })
// → 1. id=commons-xxx｜Malus law…｜800×600｜CC BY-SA 4.0｜作者
asset_download({ id: 'commons-xxx' })
// → { path: 'assets/xxx.png', license, author, source }
// 然后 kind:"image" + image:{src: path} 或 g.image(path, x, y, w, h)
```

图标/刻度/简单示意图优先用 `asset_svg({ name, svg })` 现场生成，风格统一且不用等网络。
