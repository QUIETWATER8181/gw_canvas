# 知识库方案（物理 / 数学 / 分镜）

> 2026-11-06 追加。目标：让 agent 在写场景前能查到「物理图像、数学公式、分镜节奏」，而不是只靠模型记忆。
> 结论：**不要把知识全塞进 AGENTS.md**；用按需检索的本地知识库，只返回命中的 1–2 条。

## 1. 为什么不用 AGENTS.md 全量塞

`AGENTS.md` 是每条消息都会进上下文的系统说明。往里加 20KB 知识，等于每轮都多花几千 token，
而且大部分内容跟当前任务无关。知识库按需查，查一次只返回 1–2 条（约 1–3KB），便宜且更聚焦。

## 2. 文件与格式

```
resources/knowledge/
  physics.md      物理：16 条（运动学 → 量子 + 科普叙事）
  math.md         数学：13 条（函数 → 线代/概率/TeX 写法）
  storyboard.md   分镜：11 条（五拍结构 → 模板/自检）
```

每条以 `## 标题 | 关键词` 开头，正文到下一个 `##` 结束：

```md
## 波动光学与偏振 | wave optics interference diffraction polarization 双缝 偏振 马吕斯

双缝：`Δ = d sinθ`，亮纹 `d sinθ = nλ`；条纹间距 `Δy = λL/d`。
直觉：干涉看「相位差」，衍射看「波前被限制」，偏振看「振动方向的选择」。
画面：双缝用两条相干波前 + 屏幕上的明暗条纹；偏振用两个正交振动方向 + 检偏器旋转 + `cos²θ` 曲线。
常见错误：把干涉条纹间距公式里的 `L` 当成缝宽；偏振片「透过轴」画成「振动方向」。
```

标题后的关键词用空格分隔（中英文都行），用于命中；正文里的「画面」和「常见错误」是给 agent 的落地指令。

## 3. 检索实现

`electron/main/knowledge.ts`：

- 启动时 `load(resources/knowledge)`，按 `##` 切成 section；
- `search(query, topic?, limit=2)`：
  - 中文按 2-gram 拆（「马吕斯定律」→ 马吕/吕斯/斯定/定律），英文按词；
  - 标题命中 +6、关键词 +5、正文 +1.5；整串命中额外加分；
  - 按分数排序，最多返回 4 条；
- 没命中返回 `catalog()`（按主题列标题），让模型换词；
- 主题过滤：`physics` / `math` / `storyboard`。

工具：`knowledge_search({ query, topic?, limit? })`，由 `bridge.ts` 注册，返回
`## [topic] 标题` + 正文。AGENTS.md 里要求「不确定先查，只取 1–2 条，不要贴原文」。

IPC（给界面/探针）：`window.gewu.knowledgeSearch({ query, topic, limit })`。

## 4. 覆盖范围

**物理**：运动学/抛体、牛顿定律/受力、圆周/万有引力、功与能/动量、简谐振动/机械波、
几何光学、波动光学/偏振、静电场/电势、电路、磁场/洛伦兹力、电磁感应、热学/统计、
流体/伯努利、狭义相对论、量子入门、物理科普叙事。

**数学**：函数图像、三角/单位圆、向量/点积叉积、导数、积分、微分方程、复数/相量、
线性代数/矩阵、概率统计、级数/近似、坐标几何、可视化模板、TeX 写法。

**分镜**：五拍结构、镜头类型/时长、运镜、转场、节奏、文字层级、色彩语义、声音设计、
8 个可复用分镜模板、常见错误、自检清单。

## 5. 扩展方式

1. 在对应 md 里加一个 `## 标题 | 关键词` 段落；
2. 正文按「公式/直觉/画面做法/常见错误」四段写，尽量给可执行的坐标/颜色/时长；
3. 重启应用（知识库在启动时加载）；用 `knowledge_search` 或 `--probe-file` 验证能命中；
4. 不要写太长：单条 150–400 字最佳，太长会挤占上下文。

## 6. 限制

- 没有向量检索/embedding，靠关键词 + 2-gram；同义词覆盖有限，查询时多换几个词。
- 中文 2-gram 会有误命中，靠标题/关键词权重压住。
- 矩阵/多行公式的 TeX 排版仍不支持（知识库会提示拆成多个 `g.math`）。
- 知识是「提示 + 画面做法」，不替代 `scene_render_frame` 自检。
