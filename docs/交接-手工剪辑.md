## 1. 这一轮实际做了什么

### 场景模型（`src/shared/scene.ts`、`src/shared/layers.ts`）

- `SceneLayer.kind`：`group | text | image | shape | code`（缺省 = `code`，老场景不用迁移）。
- 嵌套 `children`，typed 元素带 `x/y/w/h` + `scale/rotation`（度，绕元素盒中心）。
- `text{content,size,weight,color,align,lineHeight,maxWidth,font,background}`、
  `image{src,radius,fit,placeholder}`、`shape{type:rect|ellipse|line|arrow|triangle,fill,stroke,strokeWidth,radius}`。
- `draw` 只有 `code`（或带动画的 `group`）才有。
- `layers.ts` 是纯树工具：`flatten/findLayer/updateAt/removeMany/insertAt/moveAt/groupBox/unionBox/selfBox/cloneTree`。

### 渲染与命中（`src/engine/render.ts`、`src/components/stage-geometry.ts`）

- 递归 `paintList`，祖先 transform 用 `ctx.save/translate/rotate/scale` 叠；`path` 数组当身份。
- 命中与绘制共用同一份矩阵（`layerMatrix/worldMatrix/worldToLocal/pointInTyped`）——
  **改渲染必须同步改 stage-geometry，否则「画在这、点不中」**。
- `code` 图层没有盒子，命中靠 9×9 离屏 alpha 采样。

### 画布编辑（`src/components/Stage.tsx`，约 950 行）

- 单击选最深元素、`Alt+单击`选父组合、空白拖=框选、`Shift+拖`=框选给 AI。
- 拖动 / 8 个手柄缩放 / 旋转手柄；吸附参考线 `SNAP_PX=6`；拖动时选框实时跟随（不再冻结）。
- 双击文字 → 内联 textarea（字号/颜色/对齐跟元素一致），`Ctrl+Enter` 提交、`Esc` 取消、失焦提交。
- 右键菜单（`ContextMenu.tsx`）：副本/删除/组合/解组/上移/下移/锁定/隐藏/让 AI 改这个元素。
- 缩放平移：`Ctrl+滚轮`以光标为中心、滚轮/空格拖/中键拖平移、适应窗口；`Ctrl+0/±`。
- 键盘：方向键微调（Shift ×10）、`Del`、`Ctrl+D`、`Ctrl+G`/`Ctrl+Shift+G`、`Ctrl+[`/`]`、`Ctrl+Z`/`Ctrl+Shift+Z`。

### 时间轴（`src/components/Timeline.tsx`）

- 统一行模型：`Row{kind:'layer'|'audio'|'subtitle'}`，一对象一行；组合行带折叠箭头，展开后子元素缩进。
- 类型配色 + 类型图标（`KindIcon`）：group/text/image/shape/code/audio/subtitle。
- 剪辑块拖动与左右裁剪、吸附、`DRAG_MIME='text/gewu-asset'` 接收素材。
- 行内 `.tl-mini` 眼睛/锁按钮；右键菜单；名栏 168px、表头与名栏 sticky；高度 `clamp(210px,30vh,340px)`。
- 素材 drop：`dropAssetAt(editor, asset, t, row, design?)` —— 音频进 `scene.audio`（按落点时间），
  图片按落点生成 `kind:'image'`（画布 drop 会换算设计坐标并居中于落点）。

### 属性面板（`src/components/Inspector.tsx`）

- 类型徽标 + 按 kind 分区（文字/形状/图片/变换/时间/外观/备注）。
- 组合区：子元素列表（点一下选中）+ 解组。
- `code` 图层底部新增「让 AI 拆成组合」→ `window.gewu.sendPrompt(...)`，要求它先调 `scene_restructure`。

### AI 侧（`electron/main/agent/bridge.ts`、`resources/gewu-tools.mjs`、`resources/AGENTS.md`）

- `scene_set_layer` / `scene_delete_layer` 支持任意深度（按 id 定位，自动算路径）。
- `scene_add_layer` 支持 `parent` 与 typed 元素。
- 新增 `scene_restructure`：**只返回拆分指引，不改场景**（顶层绝对坐标；组合 x/y 建议 0、子元素相对组合）。
- `buildSceneContext` 附带的 `<scene-state>` 改成了元素树（子元素缩进）。
- `AGENTS.md`：typed-first、kind 表、组合示例、「什么时候把老场景拆成组合」、10 条硬性约定、组合子元素坐标相对。

### 归一化（`electron/main/scene-store.ts`）

- `normalizeScene` 递归清洗：`MAX_DEPTH=4`、`MAX_LAYERS=300`、kind 白名单、`draw` 只对 code 必填。

## 3. 已知坑（这一轮新踩的，已写进 `docs/开发记忆与回滚.md` 的 34–40 条）

1. **场景树三处必须同步**：`engine/render.ts`、`components/stage-geometry.ts`、`electron/main/scene-store.ts`。
   漏一处 = 画面有但点不中 / 保存后子元素消失。
2. **组合要有自己的盒子**，子元素坐标相对组合原点；`ungroup()` 加回去。
   AI 写 `children` 用绝对坐标 + 组合 `x/y≠0` → 整体偏移。
3. **`Ctrl+Z` 曾在画布聚焦时失效**：全局 keydown 里 `if (target.closest('[data-canvas]')) return`
   把撤销也挡了。撤销/重做必须放在这个守卫**之前**（`typing` 判断仍在最前）。
4. **别冻结选择框**：拖动时选框从当前 scene 现算（`liveBoxes`），只缓存手势起点的 x/y。
5. **探针拍平函数少映射字段 → 假失败**（`byName()` 查不到 `text.content`）。要么映射全，要么别拍平。
6. **满时长的剪辑块拖不动**（`dur-len=0` 是对的），探针里先裁短再拖。
7. **`--selftest` 导出的是当前打开的草稿**，`frames = duration × fps`。
8. **探针要轮询而不是死等**：写文件有延迟，用 `waitScene(pred, 8000)` 反复读，别 `wait(1000)` 后一次读。
9. **时间轴用 mouse 事件、舞台用 pointer 事件**：合成 `PointerEvent` 不会产生兼容 mouse 事件；
   合成 `MouseEvent` 才能驱动时间轴拖动/裁剪。
10. `--probe` 脚本必须是 `(async () => { ...; return JSON.stringify(out) })()` 形式；
    别包成 `new Promise`（Electron 克隆不了），也别在 `()` 前加无分号的语句（ASI 会炸）。

## 5. 手工验收清单（给用户，5 分钟）

1. 左栏拖一张图到**时间轴**上 → 出现一行图片剪辑；再拖到**画布**上 → 图出现在落点。
2. 点画布上的卡片标题 → 选框 + 8 手柄 + 旋转手柄；拖动，出现对齐参考线；松手位置留住。
3. 双击标题 → 直接改字，`Ctrl+Enter` 提交；`Esc` 取消。
4. 拖剪辑块右边缘 → 裁短；拖整条 → 移动；`Ctrl+Z` 能撤回。
5. `Ctrl+click` 选两个元素 → `Ctrl+G` 成组（时间轴出现可折叠的组合行）→ `Ctrl+Shift+G` 解组。
6. 右键画布 → 菜单 9 项；点「让 AI 改这个元素」看是否把选中元素带进对话。
7. 选中一个代码图层（老场景的「背景网格」那种）→ 属性面板底部「让 AI 拆成组合」。
8. 时间轴拖到最下面一行确认能滚到；左右拖动名栏宽度不该错位（sticky）。
