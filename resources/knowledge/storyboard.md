# 剪辑与分镜知识库

> 用法：`knowledge_search({ query: '对照实验 分镜', topic: 'storyboard' })`。
> 目标不是「炫技」，是让观众在 10–30 秒内看懂一个物理/数学关系。默认按这里的模板排，用户有明确要求再改。

## 五拍结构 | structure 叙事 三幕 钩子

**现象钩子（0–15%）→ 变量拆解（15–35%）→ 对照/控制变量（35–60%）→ 公式或图像揭示（60–85%）→ 回扣（85–100%）**。

- 钩子：一个反直觉的结果、一个对比、或一个「如果……会怎样」。
- 拆解：把复杂现象压到 1–2 个变量，画面只留必要的元素。
- 对照：只改一个变量，让观众看到差异；这是科普视频最值钱的部分。
- 揭示：先图后公式，公式只保留主项，符号和画面里的量一一对应。
- 回扣：复用开头的画面/问题，用一句话收束。

12 秒模板：0–2 钩子，2–5 拆解，5–8 对照，8–11 揭示，11–12 回扣。

## 镜头类型与时长 | shot 镜头 构图 特写

| 镜头 | 用途 | 建议时长 |
| --- | --- | --- |
| 建立镜头（establishing） | 交代场景/装置全貌 | 1.5–3s |
| 图解镜头（diagram） | 坐标轴、光路、受力图 | 3–6s |
| 公式镜头（equation） | 推导、关系式 | 2–4s |
| 对照镜头（A/B） | 两个条件并排 | 2–4s |
| 细节镜头（detail） | 一个点、一个角度、一个数值 | 1–2s |
| 回扣镜头（recap） | 复用开头画面 | 1.5–3s |

一屏最多 3 个视觉焦点；主体放在中间 60% 区域；标题在左上或顶部居中，公式在右下/底部。

## 运镜 | camera 推拉摇移 缩放 平移

- **推近（zoom in）**：强调细节/结论；`scale` 从 1 → 1.15，或用画布 `view.zoom`。
- **拉远（zoom out）**：从局部回到全局；结尾常用。
- **平移（pan）**：展示长图/时间线；让内容整体 `x` 随 `t` 移动，或移动相机。
- **跟随（follow）**：粒子/物体运动时，让相机追它；注意背景要有参照物。
- **旋转**：3D 或极坐标场景；2D 里慎用，容易晕。

原则：**一个镜头只做一种运动**；运镜要跟讲解重音同步；不要全程都在动。

## 转场 | transition 切换 渐隐 擦除

- 硬切：同一场景内的连续动作，或节奏很快时。
- 渐隐（fade）：最安全；元素 `enter/exit` 0.4–0.6s。
- 滑入/滑出（slide）：有方向含义（下一步、时间推进）；距离 60–120px。
- 缩放（zoom）：强调「进入细节」或「拉回全局」。
- 擦除（wipe）：适合对比/时间线；不要每个转场都用。

默认：**元素进场用 fade，场景切换用 0.3–0.5s 交叉淡化**；同一时刻不要让两个大元素同时硬切。

## 节奏 | pacing 时间 停顿

- 一个概念 2–4s；一句话 2–5s；公式推导每步 1.5–3s。
- 进场 0.4–0.6s，退场 0.3–0.45s；动作之间留 0.2–0.4s 的「呼吸」。
- 重要结论出现后停 0.8–1.5s，不要马上切走。
- 12s 视频 3–5 个节拍；60s 视频 12–18 个节拍；超过 20 个节拍观众会累。

## 文字与信息层级 | text hierarchy 排版 字号

- 主标题 64–84px；副标题/结论 40–56px；正文 28–36px；标注/单位 20–26px。
- 一屏最多 2 行标题 + 1 行公式 + 3 个标注；长句拆成两条字幕。
- 公式用 `g.math`，不要用普通文字硬凑上下标；单位和数字用 `\mathrm`。
- 文字出现用 `fade` 或 `typing` 音效；不要逐字动画 + 逐字音效同时上。

## 色彩语义 | color 配色 物理量

固定语义，整片不要变：

- 青蓝 `#4fc3d9`：电场/光/主量
- 金 `#f2b544`：磁场/能量/强调
- 红 `#e06c75`：力/危险/负量
- 绿 `#6ec88c`：正确/守恒/结果
- 灰 `#7d8b96`：辅助线/背景信息

背景深色 `#0d1117`；一屏高饱和色不超过 3 种；用透明度而不是更多颜色区分层级。

## 声音设计 | sound 音效 节奏

- 元素进场：`whoosh`/`swoosh`；标签/数据点：`pop`/`tick`；结论：`ding`；收尾：`success`。
- 音效卡在图层 `start`/`end`；音量 0.5–0.8，有旁白压到 0.4–0.6。
- 12s 视频 4–8 个音效；不要每个元素都配。
- 旁白一句话一条音轨，字幕 `end` 跟语音时长对齐。

## 八个可复用分镜模板 | template 模板 分镜

### 1. 现象钩子
画面：一个反直觉的结果先出现（球不落、光变暗、曲线突然翻转）。
层：`bg` + `hook-object`（code/shape）+ `hook-label`（text）。1.5–3s，结尾留 0.5s 静止。

### 2. 变量拆解
画面：把复杂装置拆成 2–3 个独立元素，其他淡出。
层：`group` 包住装置 + 每个变量一个 `text` 标签 + 一条 `arrow` 指向变量。
节奏：每个变量 0.8–1.2s 依次高亮，其余降透明度到 0.3。

### 3. 对照实验
画面：左右并排，只改一个变量；中间一条分隔线。
层：两个 `group`（A/B）+ 顶部 `text` 写「只改 X」+ 底部结论。
转场：A/B 同时 `enter`，差异量用 `chip` 标出。

### 4. 公式推导
画面：左边图、右边公式；公式一行一行出现，每一步对应图上一次变化。
层：`group` 图 + `text`/`g.math` 公式（每步一个元素，或用 code 层按 `t` 分行）。
节奏：每步 1.5–3s；当前步高亮，其余 0.35 透明度。

### 5. 图像揭示
画面：坐标轴先出，曲线从左到右画，关键点/切线最后出现。
层：`axes`（code）+ `curve`（code）+ `point`（shape）+ `label`（text）。
节奏：轴 0.5s，曲线 1.5–3s，关键点 0.3s，公式 0.5s。

### 6. 尺度缩放
画面：从宏观拉到微观（或反过来），用连续 `scale` 或相机 `zoom`。
层：`group` 整体缩放 + 尺度标签（`10^-3 m` 等）随 `t` 更新。
注意：缩放时文字不要跟着糊；文字单独一层，保持字号。

### 7. 场线/矢量场
画面：网格上小箭头/流线，颜色表示模长；粒子沿场线运动。
层：`code` 画场线（`g.glow`/`g.arrow`）+ `code` 画粒子 + `text` 标注。
节奏：场线先淡入，粒子后出现；不要同时画太多箭头（> 200 会糊）。

### 8. 时间线/历史
画面：一条水平时间轴，事件从左到右出现；当前事件高亮。
层：`code` 轴线 + 每个事件一个 `group`（点 + 年份 + 一句话）。
节奏：每个事件 0.8–1.2s；当前事件放大 1.1×，其余 0.5 透明度。

## 常见错误 | mistake 避坑

1. 一上来推公式，没有现象/直觉。
2. 所有元素同时出现，没有节奏。
3. 一屏塞 5 个以上焦点，观众不知道看哪。
4. 公式符号和画面里的量对不上（颜色/字母不一致）。
5. 转场全是硬切，或全是花哨转场。
6. 音效比画面还密。
7. 结尾不复用开头，观众没有「闭环」感。
8. 文字太小/太多，手机上看不清。

## 自检清单 | checklist 验收

- [ ] 开头 2s 内有没有「值得看下去」的东西？
- [ ] 是否只改了一个变量做对照？
- [ ] 公式出现前有没有图/直觉？
- [ ] 一屏是否 ≤ 3 个焦点？
- [ ] 元素进出场是否有 0.4–0.6s 过渡？
- [ ] 音效是否卡在画面节点、音量是否让旁白清楚？
- [ ] 结尾是否回扣开头？
- [ ] 12s 版本是否 ≤ 5 个节拍？
