# 物理知识库

> 用法：`knowledge_search({ query: '马吕斯定律', topic: 'physics' })`。
> 每条都是「公式 + 直觉 + 画面做法 + 常见错误」，写场景时优先照着画面做法落地，别只把公式贴上去。

## 运动学与抛体 | kinematics projectile 速度 加速度 抛体 自由落体

匀变速：`v = v0 + at`，`x = v0 t + ½at²`，`v² = v0² + 2ax`。
抛体：水平匀速 `x = v0 cosθ · t`，竖直匀变速 `y = v0 sinθ · t − ½gt²`；轨迹是抛物线。
直觉：把「水平」和「竖直」拆成两条独立的时间轴，再用同一个 `t` 合成。
画面：先画坐标轴和初速度箭头，再让一个点沿抛物线走，同时用两条投影线分别投到 x/y 轴；右侧放 `vx`、`vy` 两个小条形图。
常见错误：把「速度方向」画成「轨迹切线」以外的方向；忘记 `g` 只作用在竖直方向；用「上一帧位置 + 速度」做积分导致导出抖动（必须用解析式）。

## 牛顿定律与受力分析 | Newton force 受力 摩擦力 斜面 连接体

`ΣF = ma`；重力 `mg`、支持力 `N`、滑动摩擦 `f = μN`、弹簧 `F = −kx`。
直觉：先隔离物体，再把所有力画成从同一点出发的箭头；合力决定加速度，不是速度。
画面：物体方块 + 彩色受力箭头（重力红、支持力青、摩擦金），箭头长度按大小；加速度用一条虚线箭头单独标。
常见错误：把「运动方向」当成「合力方向」；斜面上把重力直接当压力；静摩擦和滑动摩擦混用；漏掉绳/杆的约束方向。

## 圆周运动与万有引力 | circular gravity 向心 万有引力 开普勒

`a = v²/r = ω²r`，`F = mv²/r`；万有引力 `F = GMm/r²`；开普勒第三定律 `T² ∝ r³`。
直觉：速度沿切线、加速度指向圆心；「向心力」不是新的力，是合力在径向的分量。
画面：圆轨道 + 切线速度箭头 + 指向圆心的加速度箭头；同步画 `v` 和 `ω` 的关系；卫星轨道用椭圆 + 面积扫过。
常见错误：把向心力画成「离心力」；认为卫星失重是因为「没有重力」；圆轨道和椭圆轨道的速度变化混淆。

## 功、能与动量 | work energy momentum 动能 势能 守恒 碰撞

`W = F·s·cosθ`，`Ek = ½mv²`，`Ep = mgh`；动量 `p = mv`，冲量 `I = FΔt = Δp`。
守恒：无外力时 `Σp` 守恒；只有保守力做功时机械能守恒；完全非弹性碰撞动能损失最大。
直觉：能量看「状态」，动量看「相互作用的时间积累」；碰撞用「动量守恒 + 恢复系数」两句话。
画面：能量条形图（动能/势能/内能）随 `t` 变化；碰撞前后用两条动量箭头做矢量相加；用「能量流失为热」的粒子抖动表示非弹性。
常见错误：把动量守恒和能量守恒混为一谈；忽略重力势能零点；二维碰撞只画一维。

## 简谐振动与机械波 | SHM wave 振动 周期 频率 波 干涉 驻波

`x = A cos(ωt + φ)`，`ω = 2πf = 2π/T`；弹簧 `ω = √(k/m)`，单摆 `ω = √(g/L)`。
波：`v = λf`；两列同频波干涉，程差 `Δ = nλ` 加强、`(n+½)λ` 减弱；驻波两端/一端条件不同。
直觉：振动是「时间上的圆」，波是「空间上的圆」；用旋转矢量（相量）把 `cos` 变成投影。
画面：弹簧振子 + 参考圆 + 投影点；波形用 `g.sineWave` 或 `g.plot`；干涉用两列波叠加后的包络。
常见错误：把 `f` 和 `ω` 混用；驻波节点/腹点标反；波速当成质点速度。

## 几何光学 | geometric optics 反射 折射 透镜 全反射 光路

反射定律：入射角 = 反射角；折射：`n1 sinθ1 = n2 sinθ2`；临界角 `sinθc = n2/n1`。
薄透镜：`1/f = 1/u + 1/v`，放大率 `m = −v/u`；凸透镜实虚焦点、凹透镜虚焦点。
直觉：光走「最短时间」路径；折射率越大越「慢」，所以靠近法线。
画面：法线虚线 + 入射线/折射线 + 角度弧；透镜用两条特殊光线（平行过焦点、过光心不偏折）定像；全反射时让折射光消失、只剩反射光。
常见错误：角度从界面而不是法线量；凸透镜成像虚实不分；把「像」画在透镜同侧/异侧搞反。

## 波动光学与偏振 | wave optics interference diffraction polarization 双缝 偏振 马吕斯

双缝：`Δ = d sinθ`，亮纹 `d sinθ = nλ`；条纹间距 `Δy = λL/d`。
单缝衍射：`a sinθ = nλ` 为暗纹；圆孔艾里斑 `θ ≈ 1.22λ/D`。
偏振：马吕斯定律 `I = I0 cos²θ`；布儒斯特角 `tanθB = n2/n1`，反射光完全偏振。
直觉：干涉看「相位差」，衍射看「波前被限制」，偏振看「振动方向的选择」。
画面：双缝用两条相干波前 + 屏幕上的明暗条纹；偏振用两个正交振动方向 + 检偏器旋转 + `cos²θ` 曲线；布儒斯特角画反射光只保留一个振动方向。
常见错误：把干涉条纹间距公式里的 `L` 当成缝宽；偏振片「透过轴」画成「振动方向」；自然光直接套马吕斯（要先取一半）。

## 静电场与电势 | electrostatics field potential 库仑 电场线 高斯 电势

库仑：`F = k q1 q2 / r²`；场强 `E = F/q`，点电荷 `E = kQ/r²`；电势 `V = kQ/r`，`E = −dV/dx`。
高斯：`∮E·dA = Q/ε0`；导体内部 `E = 0`，表面场强垂直表面。
直觉：电场线从正电荷出发、到负电荷终止；等势线处处垂直于电场线；电势是「单位电荷的势能」。
画面：场线用 `g.glow` 画流线，等势线用虚线同心圆；让试探电荷沿场线加速；用颜色深浅表示场强。
常见错误：把电场线和轨迹混为一谈（只有初速为零/沿场线时才重合）；认为电势为零处场强也为零；导体内部画场线。

## 恒定电流与电路 | circuit current Ohm Kirchhoff 电阻 电容

欧姆：`I = U/R`；串联 `R = ΣR`，并联 `1/R = Σ1/R`；功率 `P = UI = I²R = U²/R`。
基尔霍夫：节点电流守恒、回路电压和为 0；电容 `Q = CU`，RC 充电 `U = E(1 − e^{−t/RC})`。
直觉：电压是「高度差」，电流是「水流」，电阻是「管道窄处」；电容是「蓄水池」。
画面：电路用折线 + 电池/电阻/电容符号；电流用沿导线移动的小点，亮度/速度表示大小；RC 曲线同步画 `U-t`。
常见错误：把「电子移动方向」当成电流方向；并联电路里认为电阻大的支路电流大；电容在直流稳态当断路。

## 磁场与洛伦兹力 | magnetic Lorentz 磁场 右手定则 回旋 质谱

洛伦兹力 `F = qv × B`，大小 `qvB sinθ`；圆周半径 `r = mv/(qB)`，周期 `T = 2πm/(qB)`。
直导线 `B = μ0 I/(2πr)`；螺线管 `B = μ0 n I`。
直觉：右手定则——四指从 `v` 转向 `B`，拇指是正电荷受力；负电荷反向。
画面：磁场用「×/·」阵列或流线；带电粒子螺旋/圆周轨迹；速度与磁场夹角变化时半径不变、螺距变。
常见错误：右手定则三指关系用错；负电荷不反向；认为磁场力做功（它不做功，只改方向）。

## 电磁感应 | induction Faraday Lenz 楞次 感应电动势

法拉第：`ε = −dΦ/dt`；动生电动势 `ε = Bℓv`；自感 `ε = −L di/dt`。
楞次：感应电流的磁场总是阻碍原磁通变化。
直觉：磁通量「变化」才有电动势，静止在恒定磁场里没有；「阻碍」不是「相反」，是「延缓变化」。
画面：线圈 + 磁铁相对运动 + 磁通量曲线；感应电流方向用箭头和「阻碍」标注；让灯泡亮度随速度变化。
常见错误：把「磁通量大」当成「电动势大」；楞次定律方向标反；动生电动势里 `ℓ` 取错（有效切割长度）。

## 热学与统计 | thermodynamics ideal gas entropy 理想气体 热力学 熵

理想气体 `pV = nRT`；内能 `U = (i/2)nRT`；热力学第一定律 `ΔU = Q − W`。
绝热 `pV^γ = const`；卡诺效率 `η = 1 − Tc/Th`；熵变 `ΔS = ∫dQ/T`。
直觉：温度是分子平均动能的量度；压强是分子撞壁的统计效果；熵是「微观状态数」的对数。
画面：分子盒子里粒子速度分布（麦克斯韦-玻尔兹曼）；活塞压缩时粒子变密、变快；`p-V` 图上的循环。
常见错误：把「热」当成一种物质；认为绝热过程温度一定不变；熵增说成「混乱度」而不解释微观状态。

## 流体与伯努利 | fluid Bernoulli 连续性 压强 流速

连续性：`A1v1 = A2v2`；伯努利：`p + ½ρv² + ρgh = const`（理想、定常、不可压）。
直觉：管道变窄流速变大、压强变小；飞机升力/喷雾器都用这个，但别过度简化。
画面：流线管 + 截面变化 + 压强计液柱高度；粒子沿流线加速；用颜色表示压强。
常见错误：把伯努利用在黏性/可压缩流体；忽略高度项；用「流速大压强小」解释一切（需要说明前提）。

## 狭义相对论 | relativity 相对论 洛伦兹 时间膨胀 质能

洛伦兹因子 `γ = 1/√(1 − v²/c²)`；时间膨胀 `Δt = γΔτ`；长度收缩 `L = L0/γ`；质能 `E = mc²`。
直觉：光速不变 → 同时性是相对的；时空图（`ct-x`）比公式更直观。
画面：时空图 + 光锥 + 两艘飞船的世界线；时钟对比；`γ` 随 `v/c` 的曲线在接近 `c` 时爆炸。
常见错误：把「时间膨胀」说成「时钟坏了」；认为高速运动「看起来」变短而不是测量变短；用 `E=mc²` 解释所有质量。

## 量子物理入门 | quantum 光电效应 德布罗意 玻尔 不确定性

光电效应 `E = hf − W`；德布罗意 `λ = h/p`；玻尔能级 `En = −13.6/n² eV`；不确定性 `ΔxΔp ≥ ħ/2`。
直觉：能量/动量是分立的「份」；电子双缝说明「概率幅」而不是经典轨迹；测量会改变状态。
画面：光电效应用光子撞金属 + 电子逸出 + 截止电压曲线；能级图用水平线 + 跃迁箭头 + 光谱线；双缝用概率分布逐步累积。
常见错误：把「光子」画成小球；认为不确定性是「仪器不够好」；能级跃迁方向/能量差标反。

## 物理科普叙事模板 | storytelling physics 分镜 讲解

默认五拍：**现象钩子 → 变量拆解 → 控制变量/对照 → 公式或图像揭示 → 回扣生活**。
12 秒示例：0–2s 现象（一个反直觉的结果）；2–5s 只留下一个变量；5–8s 画图/公式；8–11s 改变变量看趋势；11–12s 一句话回扣。
画面：一屏最多 3 个视觉焦点；公式出现前先给直觉图；颜色固定语义（电场蓝、磁场金、力红、能量绿）。
常见错误：一上来推公式；所有元素同时出现；没有「变量只变一个」的对照；结尾不复用开头的画面。
