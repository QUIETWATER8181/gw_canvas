# 数学知识库

> 用法：`knowledge_search({ query: '导数 切线', topic: 'math' })`。
> 每条包含「定义/公式 + 直觉 + 可视化做法 + 常见错误」。公式用 `g.math` 的 TeX 子集，写完渲染一帧确认没缺字。

## 函数与图像 | function graph 一次 二次 指数 对数

一次 `y = kx + b`；二次 `y = ax² + bx + c`，顶点 `x = −b/(2a)`；指数 `y = a e^{kx}`；对数 `y = ln x`。
直觉：`k` 是斜率，`a` 是开口方向和「弯曲程度」，`e` 是「自然增长率」；对数把乘法变成加法。
画面：先画坐标轴，再让曲线随 `t` 从 `x0` 画到 `x1`（`g.plot` + `ease.span`）；关键点用圆点 + 标签；切线用一条短线段。
常见错误：二次函数顶点写成 `−b/2a` 的符号错；指数函数和对数函数画反；坐标轴没有刻度却标数值。

## 三角与单位圆 | trig unit circle 正弦 余弦 相位

`sin²θ + cos²θ = 1`；`sin(α±β)`、`cos(α±β)`；`tanθ = sinθ/cosθ`；弧度 `π = 180°`。
直觉：单位圆上「角度 → 坐标」，`cos` 是横坐标、`sin` 是纵坐标；相位差就是圆上转过的角度差。
画面：单位圆 + 旋转半径 + 投影到 x/y 轴；右侧同步画 `sin`/`cos` 波形；用 `util.wave(t, f, phase)` 做振动。
常见错误：角度和弧度混用；`sin` 曲线起点画成 1（应为 0）；相位差方向反。

## 向量与点积/叉积 | vector dot cross 投影 夹角 右手定则

点积 `a·b = |a||b|cosθ`；叉积 `|a×b| = |a||b|sinθ`，方向用右手定则；投影 `proj_b a = (a·b/|b|²)b`。
直觉：点积量「同向程度」，叉积量「张成的面积/垂直程度」；点积为 0 垂直，叉积为 0 平行。
画面：两个箭头 + 夹角弧 + 投影虚线；点积用「一个向量在另一个上的影子」；叉积用平行四边形面积 + 法向量。
常见错误：把点积结果当成向量；叉积方向左右手混用；二维叉积写成标量却硬说方向。

## 导数与变化率 | derivative tangent 斜率 变化率 链式法则

`f'(x) = lim_{h→0} (f(x+h)−f(x))/h`；`(xⁿ)' = nx^{n−1}`；`(e^x)' = e^x`；`(sin x)' = cos x`；链式 `(f(g(x)))' = f'(g)g'(x)`。
直觉：导数 = 切线斜率 = 瞬时变化率；二阶导 = 弯曲方向（凹凸）。
画面：曲线上一点 + 切线 + 一个越来越小的 `Δx` 三角形；让切点随 `t` 移动；右侧同步画导函数曲线。
常见错误：把「平均变化率」当「瞬时」；切线画成割线；链式法则漏乘内层导数。

## 积分与面积 | integral area 定积分 原函数 微积分基本定理

`∫_a^b f(x)dx` = 曲线下带符号面积；`F' = f` 时 `∫_a^b f = F(b) − F(a)`。
直觉：积分是「把无数小矩形加起来」；微分和积分互逆。
画面：曲线下用逐渐变细的矩形条填充；同时显示 `F(x)` 的累积曲线；`t` 控制矩形数量/右端点。
常见错误：忽略带符号面积（轴下为负）；上下限写反；把「面积」和「原函数」混为一谈。

## 微分方程 | differential equation ODE 指数衰减 简谐 RC

`dy/dt = ky` → `y = y0 e^{kt}`；`y'' + ω²y = 0` → `y = A cos(ωt+φ)`；RC `dU/dt = (E−U)/RC`。
直觉：方程说的是「变化率由当前状态决定」；指数/正弦是「变化率正比于自己/负比于自己」的自然结果。
画面：用 `t` 直接算解析解，不要逐帧积分；同时画 `y(t)` 和相图 `(y, y')`；参数变化时让曲线族一起动。
常见错误：用欧拉法逐帧积分导致导出漂移；把 `ω` 和 `f` 混用；初值条件没代入。

## 复数与相量 | complex phasor 欧拉 旋转 交流

`i² = −1`；`e^{iθ} = cosθ + i sinθ`；复数乘法 = 模相乘、角相加；相量把 `A cos(ωt+φ)` 表示为 `A e^{iφ}`。
直觉：复数平面上的旋转；乘 `i` 就是转 90°；交流电路的「相位差」就是两个相量的夹角。
画面：复平面 + 旋转向量 + 实部投影；相量图里两个箭头夹角表示相位差；用 `ease` 控制旋转。
常见错误：把 `i` 当成普通实数；相量角度用度数却喂给 `cos`（要弧度）；实部/虚部标反。

## 线性代数与矩阵 | linear algebra matrix 行列式 特征值 变换

矩阵乘法 `(AB)_{ij} = Σ_k A_{ik}B_{kj}`；行列式 = 面积/体积缩放因子；特征向量满足 `Av = λv`。
直觉：矩阵是「空间变换」：旋转、缩放、剪切、投影；行列式为 0 表示降维（不可逆）。
画面：网格随矩阵变换（用 `ctx.transform` 或逐点映射）；基向量 `i`/`j` 变成新箭头；特征向量方向不变、只被拉伸。
常见错误：矩阵乘法顺序交换；把行列式当成「矩阵大小」；特征向量画成任意向量。

## 概率与统计 | probability statistics 分布 均值 方差 误差

期望 `E[X] = Σx p(x)`；方差 `Var = E[X²] − (E[X])²`；正态 `p(x) ∝ e^{−(x−μ)²/(2σ²)}`。
直觉：概率是「长期频率」；方差是「离均值有多散」；`σ` 越大曲线越矮胖。
画面：直方图 + 拟合曲线；让样本数增加，直方图逐渐贴近分布；用误差棒表示不确定度。
常见错误：把「概率为 0」当成「不可能」；样本均值和总体均值混用；方差开方忘记。

## 级数与近似 | series Taylor approximation 泰勒 小角

`e^x = 1 + x + x²/2! + …`；`sin x = x − x³/3! + …`；小角 `sinθ ≈ θ`、`cosθ ≈ 1 − θ²/2`。
直觉：用多项式在一点附近逼近函数；阶数越高、离展开点越远才越准。
画面：`sin x` 与 `x`、`x − x³/6` 三条曲线叠加，随 `t` 增加阶数；误差用阴影面积表示。
常见错误：小角近似用在 `θ` 很大时；忘记说明「弧度」；泰勒展开点不是 0 却套麦克劳林。

## 坐标与几何 | coordinates geometry 极坐标 参数方程 圆锥曲线

极坐标 `x = r cosθ, y = r sinθ`；参数方程 `(x(t), y(t))`；圆 `r = R`，椭圆 `x²/a² + y²/b² = 1`。
直觉：极坐标适合「绕原点」的东西（螺旋、玫瑰线、轨道）；参数方程适合「随时间走」的轨迹。
画面：同一条曲线用直角坐标/极坐标两种画法对照；参数 `t` 用动画推进；焦点/准线用虚线。
常见错误：极坐标角度单位混用；椭圆 `a/b` 谁大谁小说反；参数范围没闭合。

## 数学可视化模板 | visualization 教学 动画

1. **图像揭示**：坐标轴先出现 → 曲线从左到右画出 → 关键点/切线 → 公式淡入。
2. **切线滑动**：曲线上一点随 `t` 移动，切线实时更新，右侧显示 `f'(x)` 数值。
3. **面积累积**：矩形条从粗到细，同时画 `F(x)` 累积曲线。
4. **向量场**：网格上画小箭头，颜色/长度表示模长；让粒子沿场线走。
5. **变换网格**：单位网格随矩阵变形，基向量高亮。
6. **相量旋转**：复平面旋转向量 + 实部投影成波形。
7. **概率累积**：直方图 + 样本数增加 + 理论曲线。
8. **3D 曲面**：`three.plane`/参数曲面，随 `t` 旋转视角或改变参数。

## TeX 子集与写法 | tex latex 公式 排版

`g.math` 支持：上下标 `x^2`/`x_i`、`\frac{a}{b}`、`\sqrt{x}`、`\vec{v}`、`\hat{x}`、`\bar{x}`、`\dot{x}`、
希腊字母 `\alpha…\omega`、`\Gamma…\Omega`、运算符 `\cdot \times \pm \leq \geq \neq \approx \propto \infty \partial \nabla \sum \int \oint`、
箭头 `\rightarrow \leftarrow \Rightarrow`、`\text{中文}`、`\mathrm{}`、`\mathbf{}`、`\left( \right)`。

推荐写法：
- 分式：`\frac{1}{2}mv^2`
- 根号：`\sqrt{v^2/c^2}`
- 下标：`I_0 \cos^2\theta`
- 积分：`\int_a^b f(x)\,dx`
- 求和：`\sum_{i=1}^{n} i`
- 矢量：`\vec{F} = m\vec{a}`
- 单位：`9.8\ \mathrm{m/s^2}`

不要用：`\begin{matrix}`（不会排版成矩阵）、`\color`、`\left\{` 多行、`\tag`、`\label`。
写完用 `scene_render_frame` 看一眼，确认没有把命令名当文字画出来。
